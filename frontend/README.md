# 🎨 CodeMorph - Front End

This folder contains all front-end assets and UI for **CodeMorph**.

---

## 📁 Files

- **`index.html`**: Main HTML structure preserving the dashboard layout with the left sidebar and side-by-side code conversion workspace.
- **`style.css`**: Complete styling including dark IDE theme, monospace code font, line number gutter, responsive panels, and animations.
- **`script.js`**: Interactive client-side behavior including real-time line numbering, code conversion, language switching, copy-to-clipboard, file download, and status toasts.

---

## 🌐 How to Run

1. **Directly in Browser**:
   Double click or open `index.html` in any modern web browser.

2. **Via VS Code Live Server**:
   Right-click `index.html` and choose **"Open with Live Server"**.

3. **Via Backend Server**:
   When the backend is running (`cd ../backend && npm start`), open `http://localhost:5000/`.
